# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Email security@staleagent.com.

Please include:

- a description of the issue and its impact
- the version you ran (`staleagent --version`)
- steps or a proof of concept to reproduce it

Do not open a public GitHub issue for a security report.

We will acknowledge the report and follow up with a fix or mitigation. Please give us a chance to ship that fix before disclosing it publicly.
